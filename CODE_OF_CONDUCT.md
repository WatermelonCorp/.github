# Code of Conduct

## Our Standard

We want Watermelon spaces to be welcoming, respectful, and constructive for everyone.

Examples of positive behavior:

- Being respectful in disagreements
- Giving actionable, kind feedback
- Sharing context instead of making assumptions
- Helping newcomers get oriented

Examples of unacceptable behavior:

- Harassment, hate speech, or discrimination
- Personal attacks or intimidation
- Publishing private information without permission
- Disruptive or bad-faith participation

## Scope

This code of conduct applies in GitHub issues, pull requests, discussions, and other project spaces managed by Watermelon Corp.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that do not align with this code of conduct.

For serious concerns, contact `watermeloncorpui@gmail.com`.
