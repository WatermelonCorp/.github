# Security Policy

## Reporting A Vulnerability

Please do not open public GitHub issues for security reports.

Send a private report to `watermeloncorpui@gmail.com` with:

- A short description of the issue
- Steps to reproduce it
- A proof of concept or screenshots if available
- The affected repository, path, and version if known

We will review the report, confirm impact, and work on a fix as quickly as possible.

## Response Expectations

- We aim to acknowledge new reports within 5 business days.
- We may ask follow-up questions while validating the issue.
- Please give us reasonable time to ship a fix before public disclosure.
