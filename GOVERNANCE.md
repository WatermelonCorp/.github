# Governance

Watermelon Corp projects are currently maintainer-led.

## How Decisions Are Made

1. Maintainers review issues and pull requests.
2. Changes that affect API shape, contributor workflow, release behavior, or project direction should be discussed before implementation.
3. When there is no prior decision recorded, maintainers make the final call and document it in the relevant repository.

## Maintainer Priorities

- Keep the projects stable and usable
- Preserve a good contributor experience
- Prefer clear, reversible changes over risky churn

As the organization grows, this document can evolve into a more formal governance model.
